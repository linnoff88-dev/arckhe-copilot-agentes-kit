Prerequisites

Almost nothing

The kit is text: it only requires Copilot enabled by your company. The tools require Python 3 and, to test the engine, Node with Playwright.

For the kit

Microsoft 365 Copilot on your work account. Copilot Studio and Power Automate for templates 04 and 05 (if you donê¢â¬â¢t have access, the templates become the specification IT will need).

git clone https://github.com/linnoff88-dev/copilot-agentes-kit

For check-v5.py

Standard Python 3. No extra packages.

python3 --version  # 3.8 or higher

For browser-test.cjs

Node 18+ and Playwright with Chromium (or Playwright already installed somewhere else, via PLAYWRIGHT_DIR).

npm i -D playwright
npx playwright install chromium
