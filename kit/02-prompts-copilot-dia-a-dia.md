# Prompts do dia a dia — achar, resumir, transformar reunião em execução

Para o Microsoft 365 Copilot (Teams, Outlook, Word, PowerPoint). Troque o que está entre `< >`.
Regra que vale para todos: **assunto com nome próprio + período + o que você quer ver no fim.**
Sem as três partes, a resposta sai genérica e a culpa parece ser da ferramenta.

## 1. Busca que cruza fontes (em vez de "onde está aquele arquivo?")

```
Reúna tudo o que temos sobre <assunto com nome próprio: ex. a máquina 14 do setor de corte>
nos últimos <período: 6 meses> — documentos, e-mails, reuniões e conversas do Teams.
Mostre: as principais decisões tomadas, quem é responsável por cada uma,
e o que ficou pendente. Cite a fonte de cada item.
```

## 2. E-mail longo → decidido / pendente / quem não respondeu

```
Resuma esta conversa. Separe em três blocos:
1. O que já foi decidido.
2. O que ainda está pendente (com quem está a pendência).
3. Quem ainda não respondeu.
Depois prepare uma resposta para os envolvidos cobrando as pendências,
com prazo de <data>, em tom <cordial / objetivo>.
```

Antes de enviar: confira nomes e prazos. O Copilot não envia nada sozinho.

## 3. Reunião → decisões, responsáveis, prazos, acompanhamento

```
Use a reunião <nome e data> (ou as anotações abaixo).
Faça, nesta ordem:
1. Resumo em até 10 linhas.
2. Decisões tomadas, uma por linha, sem "talvez".
3. Para cada decisão: responsável (um nome), tarefa e prazo.
4. Pendências que ficaram sem responsável.
5. Uma mensagem de acompanhamento para enviar aos participantes,
   em tom cordial, cobrando as tarefas com prazo.

Anotações (se não houver gravação):
<cole aqui>
```

### Checklist do pós-reunião

1. **Resumo** — em até dez linhas, o que foi tratado.
2. **Decisões** — o que ficou decidido, sem "talvez".
3. **Responsáveis** — um nome por decisão, nunca "a área".
4. **Tarefas e prazos** — o que cada responsável faz e até quando.
5. **Acompanhamento** — quem cobra, em que data, por qual canal.

## 4. Documento a partir de várias fontes (Word)

```
Use <a ata da reunião de terça>, <a planilha de indicadores> e <o procedimento antigo>.
Escreva a versão nova do <procedimento / relatório / proposta> em linguagem simples,
para <quem vai ler>. Estrutura: <seções>. Tamanho: <1 página / 3 páginas>.
Depois gere uma versão resumida de 10 linhas para a diretoria.
```

## 5. Apresentação com público e tempo (PowerPoint)

```
Apresentação de <8 minutos> para <a diretoria / gestores que não são da área>,
a partir de <documentos apontados>. Foco: o que mudou e o que precisa de decisão.
Proponha a sequência de slides e a mensagem principal de cada um.
Máximo <6> slides. Notas de apresentação para cada slide.
```

A história é sua; os números você confere contra a fonte antes de apresentar.

## Erro comum

"O que temos sobre segurança?" devolve uma lista genérica. O Copilot não sabe se você quer a
política, as ocorrências ou os treinamentos, nem de que período. Nomeie o assunto, o período e o
formato do fim.
